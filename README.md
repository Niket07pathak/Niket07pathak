## Featured Projects

### Chain-of-Thought Supervision for Compositional VQA
Repository: [Chain-of-Thought-on-CLEVR](https://github.com/Niket07pathak/Chain-of-Thought-on-CLEVR)

A controlled study evaluating whether Chain-of-Thought supervision improves compositional visual question answering on the CLEVR benchmark using BLIP-2, OPT-2.7B, and LoRA fine-tuning.

Built a preprocessing pipeline that converts CLEVR symbolic functional programs into natural-language reasoning traces, then fine-tuned and evaluated vision-language models under zero-shot, answer-only, and Chain-of-Thought supervision settings.

**Key Contributions**
- Fine-tuned BLIP-2 OPT-2.7B using LoRA on 50,000 CLEVR samples
- Evaluated model performance on 2,000 validation samples
- Improved zero-shot performance from 8.75% to 45.95% using answer-only fine-tuning
- Analyzed Chain-of-Thought performance across short and long reasoning chains
- Built reusable scripts for dataset construction, model training, evaluation, result analysis, and visualization

**Tech Stack**  
Python, PyTorch, Hugging Face Transformers, BLIP-2, OPT-2.7B, LoRA, PEFT, CLEVR, AWS EC2, Vision-Language Models

### Fairness-Aware Credit Scoring
Repository: [Fairness-Aware-Credit-Scoring](https://github.com/Niket07pathak/Fairness-Aware-Credit-Scoring)

A machine learning project focused on reducing bias in credit scoring models while preserving predictive performance. The project compares fairness-aware ML techniques across multiple real-world credit datasets and introduces a composite Responsibility Score to evaluate fairness and accuracy together.

**Key Contributions**
- Evaluated 12 fairness-aware ML models across 4 real-world credit datasets
- Developed a Responsibility Score to jointly assess fairness and predictive performance
- Built a hybrid fairness pipeline using Disparate Impact Remover and Exponentiated Gradient Reduction
- Achieved strong model performance while improving fairness metrics on HMDA data
- Used SHAP and fairness metrics to support model interpretability and responsible AI evaluation

**Tech Stack**  
Python, Scikit-learn, Pandas, NumPy, Fairness-Aware ML, SHAP, Model Evaluation, Responsible AI
